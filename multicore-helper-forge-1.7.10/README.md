# MultiCore Helper Forge 1.7.10

Legacy Forge 1.7.10 CPU utility mod for large modpacks.

Commands:

- `/multicorecpu status`
- `/multicorecpu entities`
- `/multicorecpu cleanup`

This mod does not fully parallelize Minecraft's main world tick. It creates a real worker pool for safe immutable snapshot processing and provides entity pressure tools for old heavy packs.
